### [ImuGui](https://github.com/74hamed/ImuGui)

A real-time **IMU sensor visualization and analysis platform** for Windows.

Built with C# 12, .NET 8, WinForms and OpenGL, with live serial acquisition, CSV replay, Kalman filtering, quaternion sensor fusion, interactive 3D views, calibration workflows and a fully tested layered architecture.

**Highlights**

`C#` · `.NET 8` · `WinForms` · `OpenGL` · `Sensor Fusion` · `Kalman Filtering`

### [Claude Usage Monitor](https://github.com/74hamed/claude-usage-monitor)

A dark desktop dashboard for monitoring **Claude API usage and rate-limit data** in real time.

Built with Python and CustomTkinter, with support for standard and Admin Anthropic API keys, live refresh, usage visualization, quota warnings, background networking and modular architecture.

**Highlights**

`Python` · `CustomTkinter` · `Anthropic API` · `Desktop UI` · `Async Workflows`
